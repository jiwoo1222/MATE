# MATE

영어 단어팩을 만들고 퀴즈와 오답노트로 복습하는 React 웹 앱입니다.
학습 데이터는 현재 브라우저의 `localStorage`에 저장됩니다.

## 실행

Node.js와 npm을 설치한 환경에서 저장소 루트에서 실행합니다.

```sh
npm ci
npm run dev
```

터미널에 표시되는 개발 서버 주소를 브라우저에서 엽니다.

## 명령어

| 명령어 | 용도 |
| --- | --- |
| `npm run dev` | Vite 개발 서버 실행 |
| `npm run build` | 배포용 `dist/` 생성 |
| `npm run preview` | 빌드 결과 로컬 미리보기 |
| `npm run lint` | Oxlint 검사 |
| `npm test` | 저장소·단어 입력·퀴즈 회귀 테스트 |

## 학습 흐름

1. 홈 또는 내 단어팩에서 학습할 팩을 선택합니다.
2. 영어 4지선다, 한국어 4지선다, 영어 직접 입력, 한국어로 입력 중 학습 방식을 선택합니다.
3. 퀴즈를 마치면 점수와 오답을 확인합니다.
4. 오답노트에서 틀린 단어를 다시 풀거나 개별 단어를 제거합니다.
5. 학습 통계에서 최근 풀이 기록, 정답률, 소요 시간을 확인합니다.

## 단어팩 만들기

내 단어팩의 직접 입력 화면에서 한 줄에 한 단어씩 입력합니다.
영어와 뜻을 쉼표로 구분하거나, 세로줄로 영어·뜻·관련어를 구분합니다.

```text
apple, 사과
attach | 붙이다, 부착하다 | 반의어: detach
```

영어와 뜻이 모두 있어야 단어로 읽어 들입니다. 빈 줄은 무시합니다.
Windows·Unix 줄바꿈과 CR 줄바꿈을 섞어 붙여 넣어도 각 줄을 구분합니다.
잘못된 줄 번호, 중복 영어 단어, 60개 초과를 표시하며 문제가 있으면 미리보기와 저장을 진행하지 않습니다.
여러 뜻은 쉼표로 구분합니다. 미리보기에서 이름과 단어를 확인하고 저장합니다.
기존 팩도 수정하거나 삭제할 수 있습니다.

## 기본 단어팩

토익단어DAY6부터 DAY9까지 기본 단어팩을 제공합니다.
기본팩은 최초 한 번만 자동으로 추가하며, 삭제한 기본팩은 자동으로 복구하지 않습니다.
기본팩을 수정해도 출처 정보와 생성 시각을 유지합니다.
다시 필요한 기본팩은 단어팩 화면의 기본 단어팩 목록에서 추가할 수 있습니다.
전체 수록 단어와 관련어는 [기본 단어팩 참고표](docs/default-vocabulary.md)에서 확인합니다.
참고표는 `src/App.jsx`의 `DEFAULT_PACKS`를 옮긴 것으로, 앱 데이터를 변경할 때 함께 갱신합니다.

## 저장 방식

| 키 | 내용 |
| --- | --- |
| `pack:<id>` | 단어팩 이름, 단어 목록, 생성 시각 |
| `wrongnote:<packId>` | 단어팩별 오답 목록 |
| `history:<id>` | 퀴즈 모드, 점수, 문제 수, 소요 시간, 풀이 시각 |

브라우저나 접속 주소가 바뀌면 저장소도 달라집니다.
같은 주소의 다른 탭에서 단어팩·오답·기록을 바꾸면 열린 화면에도 반영합니다.
퀴즈나 편집 중인 내용은 유지되므로, 같은 팩을 여러 탭에서 동시에 수정하면 마지막 저장이 반영됩니다.
브라우저 사이트 데이터를 지우면 저장된 학습 데이터가 사라질 수 있습니다.
서버 계정이나 기기 간 동기화 기능은 현재 구현되어 있지 않습니다.
영어 발음 재생은 브라우저의 음성 합성 기능을 사용합니다.

## 학습 데이터 백업

단어팩 화면의 **학습 데이터 백업**에서 **백업 내보내기**로 JSON 파일을 내려받습니다.
단어팩, 오답, 학습 기록, 기본팩 추가 이력을 함께 보관하며 다른 서비스의 저장소 항목은 포함하지 않습니다.

다른 브라우저에서는 **백업 가져오기**로 5MB 이하의 MATE 백업을 선택하고 항목 수를 확인한 뒤 **확인 후 복원**을 누릅니다.
파일 전체를 검증한 후 없는 항목만 추가합니다. 같은 ID의 기존 데이터는 유지하며, ID가 다른 팩은 별도 팩으로 추가됩니다.
기본팩 추가 이력은 합쳐서 삭제했던 기본팩이 재생성되는 것을 막습니다.
저장 중 오류가 나면 이미 추가한 항목을 되돌립니다. 되돌리기에도 실패하면 현재 데이터를 확인하라는 안내가 나옵니다.
사이트 데이터를 지우기 전에는 백업 파일을 별도로 보관하세요.

## 코드 구성

| 경로 | 역할 |
| --- | --- |
| `src/main.jsx` | React 진입점과 QueryClientProvider 구성 |
| `src/App.jsx` | 화면, 퀴즈, 기본 단어팩, 저장소 함수 |
| `src/BackupPanel.jsx` | 백업 파일 선택·검증·복원 확인 화면 |
| `src/backup.js` | 백업 생성, 형식 검증, 기존 데이터 보존 및 실패 복구 |
| `src/index.css` | Tailwind 로드와 전역 스타일 |
| `public/` | 로고와 아이콘 정적 자산 |
| `vite.config.js` | React 및 Tailwind Vite 플러그인 설정 |

React와 TanStack Query로 화면과 학습 데이터를 관리하며 Tailwind CSS와 Lucide 아이콘을 사용합니다.
팩·오답·기록을 변경한 뒤 해당 쿼리를 무효화해 화면 데이터를 갱신합니다.

## 문서 변경 확인

기본 단어 참고표는 원본의 영어, 한국어 뜻, 관련어와 순서를 대조합니다.
실행 방법이나 스크립트를 바꿀 때는 `package.json`과 문서가 일치하는지 확인합니다.

## 동작과 검증

4지선다 보기는 중복 단어와 같은 뜻의 오답을 제외해 구성합니다.
작은 단어팩에서 보기가 부족하면 기본 단어팩의 단어를 사용합니다.
학습을 종료하면 다음 문제로 이동하는 타이머와 발음 재생을 정리합니다.
직접 입력 정답은 유니코드와 공백을 정규화하고, 한글 조합 중 Enter로 답안이 제출되지 않도록 처리합니다.
저장 실패는 화면에 안내하고 입력 내용을 유지합니다.
통계는 최근 30개를 먼저 표시하며 **기록 더 보기**로 이전 기록을 확인할 수 있습니다.

```sh
npm test
npm run lint
npm run build
```

브라우저에서는 모바일 화면의 단어팩 생성·수정·삭제, 네 가지 퀴즈 모드,
오답노트 재시험, 새로고침 후 저장 상태, 통계 기록 더 보기를 확인합니다.
